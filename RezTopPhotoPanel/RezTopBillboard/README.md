# RezTopPhoto Billboard

Исходники широкого рекламного борда RezTop.cc.

## Состав
- `reztop_billboard.obj` — геометрия рамки и лицевой плоскости.
- `reztop_billboard.mtl` — материалы для предпросмотра в Blender/другом DCC.
- `reztop_billboard_texture.png` — оригинальный баннер должен быть добавлен отдельно.

## Геометрия
- Соотношение сторон лицевой поверхности: 3:1.
- Размер лицевой поверхности: 300 × 100 условных единиц.
- Лицевая сторона направлена по -Y.
- Рамка чёрная, изображение располагается на отдельной плоскости.

## Сборка для CS2
Это OBJ/MTL исходники, не готовый ресурс Source 2. Для игры импортируй OBJ в Blender/Source 2 Workshop Tools, назначь баннер как текстуру материала Photo_Surface, затем скомпилируй материал/текстуру и модель в ресурсы Source 2 (.vmat_c/.vtex_c/.vmdl_c).

Важно: CounterStrikeSharp не может просто назначить произвольный PNG модели во время игры. Для смены изображения потребуется заранее подготовленный Source 2 материал/текстура либо отдельный поддерживаемый механизм доставки и загрузки ресурсов клиентам.

**Примечание:** PNG-баннер не включён в этот коммит; в текущем GitHub-подключении доступна запись текстовых исходников, но не передача бинарных файлов. Добавь оригинальный PNG в эту папку через веб-интерфейс GitHub с именем `reztop_billboard_texture.png`.
