# RezTop PhotoPanel — универсальная геометрия фотопанели

Это отдельная папка исходников модели для RezTop PhotoSystem.

## Что здесь есть
- `photo_panel.obj` — плоская прямоугольная панель 16:9 с UV-развёрткой.
- `photo_panel.mtl` — шаблон материала для DCC-предпросмотра.
- `generate_panel.py` — Blender-скрипт, который создаёт панель нужного размера и экспортирует FBX.

## Важно про CS2 / Source 2
OBJ/FBX и MTL здесь являются исходниками для подготовки ресурса, а не готовыми игровыми файлами. CS2 не загрузит их как готовую модель. В Counter-Strike 2 Workshop Tools нужно:
1. Импортировать FBX в проект аддона.
2. Создать материал Source 2 (.vmat) и назначить фото как текстуру.
3. Скомпилировать модель в .vmdl_c и материал/текстуру в игровые ресурсы.
4. Раздать скомпилированные ресурсы клиентам через поддерживаемую сервером систему загрузки/Workshop.
5. Указать путь к модели в конфиге RezTop PhotoSystem.

Одна геометрия панели подходит для всех изображений, но сами изображения всё равно должны быть подготовлены как Source 2 текстуры/материалы. Простая замена JPG на FTP сама по себе не обновляет игровой материал.

## Размер
Базовая пропорция 16:9. В Blender-скрипте можно задать ширину и высоту. Для портретных фото используй отдельную геометрию с портретным соотношением сторон или корректно вписывай картинку в материал, чтобы не растягивать её.

## Blender
Открой Blender, перейди в Scripting, загрузи `generate_panel.py` и нажми Run Script. FBX появится рядом со скриптом как `photo_panel.fbx`.
