# RezTopPhoto

Отдельный репозиторий проекта фотографий для CS2 / CounterStrikeSharp.

## Структура
- `RezTopPhotoSystem/` — исходники серверного плагина, интеграция K4-WorldText-API, WASDMenuAPI и MySQL.
- `RezTopPhotoPanel/` — исходники универсальной плоской панели и скрипт экспорта из Blender.

## Важно
В репозитории находятся исходники, не готовая DLL и не скомпилированные ресурсы Source 2. Для показа изображения в CS2 требуется подготовить модель/материал/текстуру через Counter-Strike 2 Workshop Tools. Текущий код плагина требует проверки сборкой с точными версиями API DLL с сервера.
